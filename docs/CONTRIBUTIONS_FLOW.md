# Contributions Flow

## Definition
A contribution is any verifiable input into a project:
- Analysis
- Code
- Legal review
- Research
- Coordination

## Lifecycle
1. User submits contribution (status: submitted)
2. Coordinators review
3. Decision:
   - accepted → reputation awarded
   - rejected → optional penalty
4. All decisions are audited

## Permissions
- Only active cell members can submit
- Only coordinators/facilitators can decide

## Guarantees
- No silent edits
- No hidden decisions
- Full audit trail

## Design goal
Encourage meaningful participation without gamification abuse.
