# Reputation System

## Purpose
Reputation reflects **verified, accepted contributions** to the Earthlings ecosystem.

It is:
- Non-transferable
- Non-financial
- Derived from actions, not promises

## Sources
Reputation is generated by:
- Submitting contributions
- Accepted contributions
- Coordination and facilitation roles (future)

## Storage
- Atomic events stored in `reputation_events`
- Aggregated scores stored in `reputation_scores`

## Calculation
Reputation is calculated as:
```
score = SUM(weight of events)
```

Breakdowns are preserved for auditability.

## Recalculation
- Automatic after important events
- Can be triggered manually (admin or self)
- Fully reproducible from events log

## Why not on-chain
- Requires frequent updates
- Needs reversibility
- Must respect privacy
